# Banque Misr Mobile App - Internship Project

## Overview
This iOS mobile app is designed to manage and perform banking transactions for Banque Misr. It allows users to securely view their account information, transfer funds, check balances, and perform other essential banking functions.

## Features
- **User Authentication**: Secure login and registration with email and password.
- **Account Management**: View account balance and transaction history.
- **Money Transfer**: Transfer funds between accounts.
- **Transaction Notifications**: Receive updates on transaction status.
- **Security**: Implemented with encryption for sensitive data.

## Technologies Used
- Swift
- UIKit
- CoreData (for local data storage)
- Alamofire (for networking)
- Firebase (for authentication)

## Requirements
- Xcode 12.0 or later
- iOS 14.0 or later
- CocoaPods (for dependencies)
